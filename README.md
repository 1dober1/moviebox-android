# Моя Кинотека

Лабораторная работа №5.1. Android-приложение с данными о фильмах из TMDB.

Есть популярные фильмы, поиск, избранное и список просмотренных с личными оценками и заметками.
Нажатие на карточку открывает описание фильма. Оценка, заметка и отметка «Просмотрено» сохраняются кнопкой «Сохранить».
После пересмотра оценку и заметку можно изменить.

Ранее загруженные фильмы доступны без интернета. Избранное, оценки и заметки хранятся на устройстве.

Стек: Kotlin, MVVM, Retrofit, Room, StateFlow, Glide, RecyclerView, ViewBinding.

## Запуск

1. Открыть проект в Android Studio.
2. Получить API Key (v3 auth) в [настройках TMDB](https://www.themoviedb.org/settings/api) и добавить в `local.properties`:

   ```properties
   TMDB_API_KEY=ваш_ключ
   ```

3. Выполнить Gradle Sync и запустить приложение. После смены ключа нужна пересборка.

Сборка и проверка:

```sh
./gradlew :app:assembleDebug :app:lintDebug
```
